IronVault

3e projet réalisé durant ma formation, il s'agit d'une application permettant de stocker les créations visuelles (AI générated images) crées pendant la formation. Il est possible de créer, éditer, commenter, réagir et supprimer les créations. L'application est codée avec React pour le frontend et Express pour le backend, avec mongodb pour la base de données. Le projet à été réalisé seul et m'a permis de mettre en pratique mes compétences en développement full stack, notamment la gestion de l'état avec React et la création d'API REST avec Express. Le projet à été déployé via Render pour le backend et Netlify pour le frontend.

Arbordiag

Ebauche d'application développée pour un ami visant à l'assister dans le diagnostic arboricole. L'application permet de saisir les symptômes observés sur un arbre et de fournir des suggestions de diagnostics possibles. Le projet est encore en cours de développement, mais il utilise une base de données SQL pour stocker les informations sur les arbres et les symptômes, Express pour gérer les requêtes côté serveur, et React pour l'interface utilisateur côté client. L'admin peut créer des templates de diagnostic et les utilisateurs peuvent les remplir pour obtenir des suggestions de diagnostics basées sur les symptômes saisis. L'application vise à être un outil pratique pour les arboriculteurs et les passionnés d'arbres afin de faciliter le processus de diagnostic et de prise de décision en matière de soins arboricoles.

SQL Express React
