[IronVault]

3e projet réalisé durant ma formation, il s'agit d'une application permettant de stocker les créations visuelles (AI générated images) crées pendant la formation. Il est possible de créer, éditer, commenter, réagir et supprimer les créations. L'application est codée avec React pour le frontend et Express pour le backend, avec mongodb pour la base de données. Le projet à été réaliser seul et m'a permis de mettre en pratique mes compétences en développement full stack, notamment la gestion de l'état avec React et la création d'API REST avec Express. Le projet à été déployer via Render pour le backend et Netlify pour le frontend.
